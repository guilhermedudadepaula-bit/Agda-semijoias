1 Hospedagem & PWA

Publique este HTML na Vercel ou Netlify gratuitamente. Ele ativará automaticamente o HTTPS necessário para instalar o PWA no celular do usuário.

2 Integração Tiny ERP

No painel do Tiny ERP em Configurações > API, gere o Token API Gratuito. Use o endpoint `/produtos.pesquisa.php` para sincronizar o estoque das semi jóias.

3 Sincronia Nuvemshop

Cadastre um Webhook em Nuvemshop Developers para o evento product/updated. Quando o estoque mudar na maleta, a reserva reflete na loja.
